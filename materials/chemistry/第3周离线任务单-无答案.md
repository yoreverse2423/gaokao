# 化学第3周原创任务单（2026-11-30起）

周二是当天小必做，其余可选；夜间累了跳过。学校同类作业可抵扣，不叠加训练。全部为纸面题，不自行实验。□只填最简整数系数（1也写出）。本页无答案，不含教师批改稿。

本周主题：氧化还原反应
本周目标：会标化合价、双线桥，会用得失电子守恒配平

## 周二 · 傍晚 · 25分钟（练习）【小必做】

氧化还原基础配平5题，25分钟到即停，剩余不追加。配平各式，圈出化合价改变的元素；仅第1题画双线桥、注明得失电子总数。不确定处画问号，手机可用时提交。

（1）□Fe + □O2 —点燃→ □Fe3O4
（2）□Cu + □O2 —加热→ □CuO
（3）□H2 + □CuO —加热→ □Cu + □H2O
（4）□C + □O2 —点燃→ □CO2
（5）□Mg + □O2 —点燃→ □MgO

## 周三 · 晚自习 · 20分钟（背诵）【可选】【晚自习①·20分钟】

请使用配套「第3周离线背默单-无答案.md」：提前抄下或打印，无需手机。只回忆已经学过的概念，不做配平计算。默写前不要翻看「第3周概念对照-学生版.md」；默完后如需核对，可对照学校教材或该对照页。不会处留空画问号，不联网查答案；手机可用后提交，未完成不补量。

## 周四 · 夜间 · 25分钟（练习）【可选】【夜间，累了跳过】

氧化还原配平5题，25分钟到即停。甲、乙为漏写的产物，先补化学式再配平；其余题给定全部反应物和产物。仅第2题写氧化剂、还原剂和转移电子总数；其余只配平。

（1）□Fe + □H2O(g) —高温→ □Fe3O4 + □H2
（2）□FeCl2 + □Cl2 → □FeCl3（溶液中通入氯气）
（3）□MnO2 + □HCl(浓) —加热→ □MnCl2 + □Cl2↑ + □〔物质甲〕
（4）□FeCl3 + □KI → □FeCl2 + □KCl + □I2（溶液反应）
（5）□Cu + □HNO3(稀) → □Cu(NO3)2 + □NO↑ + □〔物质乙〕

## 周五 · 午间 · 25分钟（错题）【可选】

本周错题回看，最多25分钟，不另加新题：从周二或周四自己标问号、或经批改做错的题中只选1道，遮住原解独立重做，再用一句话写卡点（化合价、电子数或原子守恒）。没有错题或尚未提交批改就跳过，不预设已经出错。手机可用时提交。
