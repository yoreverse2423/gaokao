# 化学第3周概念对照（学生版）

本页只供晚自习默写前的预习，或默写后对照；不是本周15道配平题的答案，也不指出周四「物质甲／乙」是什么。晚自习开始后先按「第3周离线背默单」闭卷写，不要边看边抄。学校教材同名章节也可对照。

1. 化合价升高、失去电子的过程叫氧化；化合价降低、得到电子的过程叫还原。
2. 氧化剂在反应中得到电子，发生还原反应，生成还原产物；还原剂失去电子，发生氧化反应，生成氧化产物。
3. 常见情况（仍要看具体反应）：O₂、Cl₂、酸性KMnO₄ 通常作氧化剂；Zn、CO、H₂ 通常作还原剂。
4. 不能只因为一种物质含有某元素，就不看具体反应，断定它在任何反应里都是氧化剂或还原剂。
